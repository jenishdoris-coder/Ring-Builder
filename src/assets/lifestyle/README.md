The portrait gallery composites at 1600 × 1600 using a cropped 512 × 512 transparent WebGI ring/shadow layer. The photograph stays in Canvas2D; it is not uploaded to WebGL. Enlarging or zooming a portrait reuses the cached composite and does not trigger enhancement. The source photograph is 1254 × 1254. Ordinary studio images remain 1200 × 1200, with bounded larger exports on enlargement. Finger placement is calibrated in `src/config/lifestylePhotos.ts`; occlusion uses camera-ray/finger-volume intersections and the measured bore. Captures run serially and hold the last live frame until the actual live camera draws again.
